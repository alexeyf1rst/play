# Исторические версии

Это самостоятельные статические сборки, доступные из общего меню версий.

| Сборка | Исходный коммит | Механика |
| --- | --- | --- |
| classic | 56a9987e93d44e2f8cafb7e98ebfc9b6cf47fa83 | исходная игра |
| improved | 4464ef81aca4ee78eec648d15377bde67deb9788 | мягкие холмы, топливо, помощь и награды |
| boost | fea0f93db40e05993e36b36557507f8347b07a68 | разгон, посадки, задания |

От исходников отличаются только ключ сохранения, выключенная по умолчанию
музыка, подключение общего меню и `<base>` для маршрутизации без завершающего
слеша. Сборки сохраняют собственные JS/CSS/иконки/манифесты и не получают новую
графику при изменении текущей версии. Не редактируйте их баланс вместе с корневым.
Общее меню и его оформление лежат в корневых `js/versions.js` и `css/versions.css`.
