# Тихие холмы

Чёрно-белая игра для расслабления. Две половины в одной:

* **Заезды** — как Hill Climb Racing: холмы, физика подвески, топливо, монеты.
  Пять машин, каждую можно не только прокачать, но и настроить под себя.
* **Долина** — как Clash of Clans, только тихо: шахты, буры, склады, ветряки.
  Они работают, пока ты спишь, и копят добычу к твоему возвращению.

Всё серое намеренно. Никаких вспышек, всплывающих наград, таймеров с обратным
отсчётом и «ещё +200% только сегодня». Музыка — медленный эмбиент, который
считается прямо в браузере и каждый раз звучит чуть иначе.

## Как запустить

### На Vercel (то, что нужно для телефона)

Собирать нечего — это чистая статика, `vercel.json` уже лежит в репозитории.

**Через сайт:**

1. [vercel.com](https://vercel.com) → **Add New… → Project**
2. **Import Git Repository** → выбери `alexeyf1rst/play`
   (в первый раз Vercel попросит доступ к GitHub — дай ему этот репозиторий)
3. **Framework Preset: Other**. Build Command, Output Directory и Install
   Command оставь пустыми — ничего собирать не надо
4. **Deploy** → через полминуты будет ссылка вида `https://play-xxxx.vercel.app`

Основная ветка репозитория сейчас `claude/dreamy-brown-uim1j2`, Vercel возьмёт
именно её и ничего настраивать не придётся. Если потом сольёшь всё в `main` —
поменяй ветку в **Settings → Git → Production Branch**. Каждый следующий push
в эту ветку выкладывается сам.

**Через терминал:**

```bash
npm i -g vercel
cd play
vercel          # первый раз спросит про проект
vercel --prod   # выложить в прод
```

Что уже прописано в `vercel.json`: статика без сборки, адрес без `/index.html`
и `Cache-Control: must-revalidate` на html/js/css — чтобы после правки баланса
изменения были видны сразу, а не через сутки кэша.

### На телефон

Открой ссылку → **Поделиться → На экран «Домой»**. Игра запустится на весь
экран, без адресной строки, со своей иконкой — как обычное приложение.
Манифест и иконки для этого уже есть.

### Просто открыть на компьютере

Скачай папку и открой `index.html` двойным кликом. Никакой сборки, npm и
сервера: чистый HTML, CSS и JS, всё работает прямо из файла.

### На GitHub Pages

**Settings → Pages → Source: Deploy from a branch**, ветка — та, где лежит
игра, папка `/ (root)`. Адрес будет `https://<ник>.github.io/play/`.

## Управление

| | |
|---|---|
| Газ | `→` или `пробел` |
| Довернуть в воздухе | тот же газ (носом вверх) и тормоз (носом вниз) |
| Тормоз и задний ход | `←` |
| Пауза | `Esc` |
| На телефоне | две круглые педали снизу |
| Долину | таскай пальцем/мышью, по участку — нажми |

В воздухе газ задирает нос машины, тормоз опускает. Заезд кончается, когда
голова водителя коснётся земли или кончится топливо. В любой момент можно
нажать паузу и закончить заезд самому — всё заработанное останется.

**Про трамплины.** На трассе не только холмы: примерно каждые 60–70 метров
попадается фигура — трамплин с крутой губой, стол, яма или череда кочек.
С них и улетаешь. Первые полторы сотни метров фигур нет совсем, дальше они
входят в силу постепенно, так что начало заезда спокойное.

**Про кувырки.** В воздухе газ крутит машину назад, тормоз — вперёд.
Полный оборот приносит 110 монет, второй в том же прыжке — вдвое больше,
третий — втрое. Долгий прыжок без кувырка тоже оплачивается. Насколько
быстро машина крутится, зависит от неё самой: мотоцикл делает оборот за
секунду, трёхосный вездеход не успевает никогда.

**Про топливо.** Полного бака хватает примерно на 40 секунд езды — дальше
живёшь канистрами, которые попадаются каждые ~200 метров. Собираешь их
все — едешь долго; пропустил две подряд — приехал. Бак растягивается
прокачкой, а чем дальше от старта, тем выше холмы и тем сложнее не
промахнуться. Так у заезда и появляется естественный финал.

## Пять этапов

Каждый этап — своё покрытие и свои правила. Чтобы открыть следующий,
хватит **бронзы** на текущем: у каждого этапа три цели по расстоянию —
бронза, серебро, золото.

| № | Этап | Чем отличается | Цели, м | Награда |
|---|---|---|---|---|
| 1 | Холмы | Мягкие волны и трамплины, место для обучения | 500 / 1200 / 2200 | ×1.00 |
| 2 | Песочница | Песок вязкий: сцепление ×0.62, качение ×2.6 — разгон тонет | 400 / 900 / 1700 | ×1.35 |
| 3 | Хайвэй | Гладко и быстро: сцепление ×1.2, качение ×0.6 | 900 / 2000 / 3600 | ×1.60 |
| 4 | Луна | Гравитация вполсилы, длинные прыжки | 550 / 1300 / 2400 | ×2.10 |
| 5 | Лес | Деревья стоят на дороге: снести можно, но машина теряет ход | 550 / 1300 / 2300 | ×2.60 |

Деревья в лесу — настоящие препятствия, а не декорация: у каждого своя
координата, машина их сносит, теряя почти половину скорости, и сломанные
остаются лежать до конца заезда.

## Пять машин

| Машина | Колёса | Разгон | Скорость | Сцепление | Оборот в воздухе |
|---|---|---|---|---|---|
| Джип | средние, r21 | 1250 | 950 | 1.00 | 1.5 с |
| Скутер | маленькие, r14 | 1450 | 820 | 0.90 | 1.0 с |
| Болид | низкие, r16 | 2165 | 1500 | 1.28 | 1.2 с |
| Трак | огромные, r36 | 1120 | 980 | 1.32 | 1.7 с |
| Луноход | большие, r30 | 1130 | 900 | 1.45 | 1.4 с |

Болид разгоняется вдвое резче трака и на хайвэе никого не видит в
зеркалах, но цепляет днищем каждую кочку. Скутер на маленьких колёсах
экономный и вертлявый, только кочки для него — стена. Луноход **немного
парит**: в воздухе его тянет вниз на 38% слабее остальных, отсюда очень
долгие прыжки.

## Тюнинг

Сверх обычной прокачки (двигатель, шины, подвеска, бак, магнит) у каждой
машины есть **тюнинг** — он ничего не стоит и крутится в любой момент:

| | |
|---|---|
| Привод | полный, задний или передний |
| Передача | короткая тянет в гору, длинная даёт скорость |
| Жёсткость подвески | мягкая глотает кочки, жёсткая точнее держит |
| Ход подвески | длинный прощает приземления, но машина валкая |
| Давление в шинах | ниже — цепче, выше — легче катится |
| Развесовка | назад — лезет в гору и встаёт на дыбы, вперёд — устойчивее |
| Управление в полёте | как резко машина крутится от газа в воздухе |

Это не подписи для вида: каждый ползунок — множитель в расчёте физики.
Заводские настройки возвращаются одной кнопкой.

## Деньги

Монетка у старта стоит 10, и **каждые пройденные 100 метров добавляют к
ней ещё 5**. На тысячном метре одна монета приносит уже 60. Поэтому
выгодно не собирать всё подряд у старта, а уезжать дальше — и поэтому
быстрые машины окупаются.

## Звук

Двигатель считается на месте: пила, частота которой идёт за оборотами
ведущего колеса, плюс октава снизу для тела, фильтр, открывающийся по
газу, шум пробуксовки и ветер на скорости. Ноты нет — есть настоящий
тон, который тянет вместе с машиной.

## Значки

В игре один набор значков на всё: 44 символа, нарисованных одной линией
и лежащих прямо в `index.html`. Цвет наследуют от текста, поэтому
одинаково работают в светлой и тёмной теме, и ничего не грузится из сети.

Значки стоят там, где помогают: на кнопках, у ресурсов, у каждой линии
прокачки и каждого ползунка тюнинга, у типов заданий, в строках итогов
заезда, в заголовках настроек и рядом с названиями построек.

## Долина

База — не плоская полка с домиками, а долина в три плана, уходящих вглубь:

* двенадцать участков разложены по **трём уступам**: ближний в полный
  размер, средний — 0.8, дальний — 0.6, и каждый следующий бледнее, потому
  что между планами лежит дымка и дальний край выцветает к небу
* у каждого уступа видна **стенка с камнем** и освещённая кромка, так что
  ярусы читаются как высота, а не как полоски
* постройки стоят **с боковой гранью** — тем же силуэтом, но одним тоном и
  со сдвигом, отсюда ощущение толщины
* по долине идёт **жизнь**: вагонетка катается по узкоколейке среднего
  яруса, над головой ползёт **канатка** с двумя бадьями руды, из трубы
  мастерской тянется дым, крутятся ветряки
* спереди кадр закрывает **тёмная кромка** с прудом, камышом и травой, а
  сзади — дальние гряды; на уступы ведут лестницы, у въезда стоят ворота
  «ДОЛИНА» и твоя машина

Долина шире экрана: её **тянут пальцем** (или мышью) влево-вправо.
Открывается она чуть левее центра, так что все четыре стартовых участка
видны сразу — даже на телефоне. Постройки на любом плане нажимаются
пальцем, у дальних просто меньше и сама постройка, и зона нажатия.

## Как разложен экран

Элементы разнесены по смыслу, а не собраны в кучу:

* **сверху слева** — что у тебя есть: монеты и руда
* **сверху справа** — служебное: музыка и настройки
* **снизу слева** — куда вкладываешь: гараж и магазин
* **снизу по центру** — главное действие: «Поехать», крупной кнопкой
* **снизу справа** — цели: задания с кружком готовых

В заезде так же: слева расход (топливо), по центру главное число
(метры), справа заработок и пауза. На телефоне «Поехать» уезжает в
отдельный ряд во всю ширину, остальное — под ним.

## Задания

Три списка: **на день**, **на неделю** и **на месяц**. Обновляются сами по
местному времени — день в полночь, неделя в понедельник, месяц первого
числа. Список собирается из даты, поэтому в течение периода он не меняется,
а в следующем будет другим.

В каждом списке обязательно есть трюковое задание — сальто, время в
воздухе или канистры. Раньше выпадали одни «проехать столько-то метров»,
и это было скучно.

Списки разложены по вкладкам — **День · Неделя · Месяц**, за раз видно
только один, а на вкладке горит кружок с числом готовых наград. У каждого
задания свой значок, так что список читается взглядом.

Задания считают то, что ты и так делаешь: расстояние за заезд и всего,
монеты, сальто, время в воздухе, руду, канистры, сбор добычи с базы,
постройки. Награда — монеты и руда, забирается кнопкой. На кнопке
«Задания» висит кружок с числом готовых. Незабранная награда исчезает
вместе со старым списком, так что заглядывай.

## Куда сохраняются данные

Игра целиком офлайновая: никаких аккаунтов, серверов и сбора данных.
Прогресс лежит **только у тебя**, тремя способами.

### 1. Память браузера — само собой

Игра пишется в `localStorage` браузера каждые несколько секунд, при уходе со
вкладки и при закрытии. Ничего нажимать не нужно.

Важно знать: это хранилище привязано к **браузеру + адресу сайта**. Значит,
сейв не переедет сам с компьютера на телефон, а «очистить данные сайтов»
в настройках браузера его сотрёт. Отсюда — два запасных способа.

### 2. Файл `.json` — бэкап и перенос

**Настройки → Сохранить в файл.** Скачается `quiet-hills-20260911-1830.json` —
обычный текстовый файл, его можно положить в облако, отправить себе в
мессенджер или закинуть в этот же репозиторий. Обратно — **Загрузить файл**.

Это самый надёжный вариант: делай так раз в несколько дней, и потерять
прогресс уже не выйдет.

### 3. Код-строка — самый быстрый перенос

**Настройки → Скопировать код.** В буфер ляжет строка вида `QH1:eyJ2IjoxL...`
Отправь её себе в любой чат, открой игру на другом устройстве, вставь в поле
в настройках и нажми **Применить код**. Прогресс переедет целиком.

### Песочница для проверки

**Настройки → Песочница.** Там можно выдать себе любое число монет и руды,
разом открыть все машины, маршруты и участки, прокачать машину в максимум,
закрыть все задания или прокрутить час работы шахт. Удобно, когда хочется
посмотреть всю игру сразу, не накатывая часы.

Из консоли браузера то же самое делается одной строкой:

```js
HC.Game.state.coins = 1e9; HC.Game.state.ore = 1e6; HC.UI.refreshTop(); HC.save(HC.Game.state, true)
```

Если хочется потом вернуться к честному прогрессу — сохранись в файл
**до** того, как накрутишь.

### Что удобнее

* Играешь на одном устройстве — ничего не делай, автосохранения хватает.
* Хочешь спокойствия — раз в неделю жми «Сохранить в файл».
* Играешь и на компьютере, и на телефоне — переноси кодом. Игра не сливает
  два прогресса в один, а **заменяет** один другим, так что переноси всегда с
  того устройства, где играл последним.

Если браузер запретил запись (приватное окно, жёсткие настройки), игра честно
скажет об этом в настройках — тогда сохраняйся в файл вручную.

## Как крутить под себя

Почти всё, что хочется подправить, лежит в `js/data.js` — это обычные числа
с комментариями. Поменял, обновил страницу, играешь.

* **Шахты кормят слишком медленно** → `HC.BUILDINGS.mine.rate`
* **Дорого прокачиваться** → `HC.UPGRADES.*.base` и `.mult`
* **Топливо кончается быстро** → `HC.VEHICLES.*.burn` или `HC.ECON.fuelPickup`
* **Холмы слишком пологие/крутые** → `HC.TRACKS.*.amp` (высота) и `len`
  (длина волны). Чем меньше `len` при той же `amp` — тем круче склоны.
* **Машина легко встаёт на дыбы** → `HC.VEHICLES.*.react`.
  Осторожно: выше ~1.1 у лёгких заднеприводных машина начинает
  опрокидывать саму себя на старте
* **Вяло крутится в воздухе** → `HC.VEHICLES.*.airCtrl` (у каждой свой)
  или общий `HC.WORLD.airControl`
* **Канистры попадаются редко/часто** → вероятность в `js/terrain.js`,
  строка `if (r2 < 0.024)`
* **Холмы слишком быстро усложняются** → `Terrain.prototype.hard` в
  `js/terrain.js`
* **Задания слишком жирные или жадные** → `HC.QUEST_KINDS` и
  `HC.QUEST_PERIODS` в `js/quests.js`
* **Пределы ползунков тюнинга** → `HC.TUNING`
* **Копилка офлайна мала** → `HC.ECON.offlineHoursBase` и склады

Физика настроена так, чтобы держаться при любых разумных числах: пружины
подвески считаются от массы машины, а не задаются вручную.
